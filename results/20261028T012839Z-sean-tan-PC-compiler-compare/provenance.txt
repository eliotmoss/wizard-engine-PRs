---- builds (cmprev.sh REV PROG)

date stamp and git count fixed to constants so that bin/Build-x86-64-linux.v3
is the same for both; then ./build.sh PROG x86-64-linux with the compiler's
bin/ first on PATH (build.sh finds v3c and VIRGIL_LOC through PATH).

---- comparison
cmpbin.py: nm -S for each function's address and size; objdump -d with every
numeric constant masked, per function. Output: compare.txt.
classify.py: every constant that differs within an otherwise equal
instruction, classified as a data address (>= 0x100000) or a smaller value,
with each smaller value and each other difference listed. Output: classify.txt.
sizes.txt: the twelve binaries' sizes.
